# Paragon Tweaks (https://paragontweaks.net/) — UI/UX Audit

Purpose: concrete, build-ready reference so another site can be rebuilt to mirror Paragon Tweaks' structure, layout, interactions and page behaviors. Everything below is pulled from the production bundle (`assets/index-BwVDEU2P.js`, `assets/index-CTZlVx6y.css`, the lazy route chunks, the prerendered `home.html`) and the saved screenshots in `shots\`. Hex codes, px values and copy are verbatim from source unless marked "observed".

Tech stack (matters for mirroring behaviors): **Vue 3 + Vue Router (history mode) + Pinia + VueUse, built with Vite**, Font Awesome 7 (SVG/JS, `fas` solid icons), Stripe (checkout), Discord OAuth2 PKCE login, Twitter/X ads pixel. Home page is prerendered to static HTML (`<!-- prerendered by scripts/prerender.mjs -->`, `<html data-static-arrival>`); every other route is a lazy chunk.

Source files on disk (scratchpad):
- `assets/home.html` — prerendered SPA shell (head meta, JSON-LD, full home markup)
- `assets/index.css` / `pretty/index.css` — main CSS (prettified copy)
- `assets/index.js` / `pretty/index.js` — main app bundle (nav, footer, home sections, cookie notice, modal, auth, cart, router)
- `assets/chunks/*` — all 51 lazy chunks downloaded from the site (page views + their CSS); `pretty/chunk-*.js`, `pretty/css-*.css` prettified; `pretty/outline-*.txt` ordered copy/structure outlines
- `services-parsed.txt` — computed-style dump of /services (banner, section, first product card)
- `shots/` — 27 screenshots (see section H)

Router `scrollBehavior`: restores saved position on back/forward; `/services/<Section>` scrolls to the section element with the offsets above; otherwise scroll to `{left:0, top:0}` unless `meta.disableScrollToTop`. A global `beforeEach` (i) sets `document.title`, `<meta name=description>`, canonical `<link>`, `og:*`, `twitter:*` and a `robots noindex,nofollow` meta for noindex routes; (ii) captures `?ref=<code>` (case-insensitive key `ref`) into `sessionStorage["paragon_affiliate_ref"]`, strips it from the URL with `history.replaceState`, and broadcasts it across tabs; (iii) guards `/admin`.

### Fonts

- **Amenti** (display/headings, buttons, nav, prices, card titles). Self-hosted TTF `@font-face`, `font-display: swap`: `Amenti-Black` 900, `Amenti-Bold` 700, `Amenti-Medium` 500, `Amenti-Regular` 400 (`/assets/Amenti-*.ttf`). The whole app root `.primaryBody` is `font-family: var(--font-primary); font-weight: 400`, so anything not explicitly set to `--font-body` renders in Amenti (geometric, wide, rounded — see "Our Services" banner title at 400 weight vs "Max Performance." at 900).
- **Roboto** is *declared* as body font but **never loaded** (no `@font-face`, no Google Fonts `<link>`) — it falls back to `Inter` → system UI (`Segoe UI` on Windows, as in the screenshots). Body copy, descriptions, labels, form fields, footer links all use `var(--font-body)`.
- **JetBrains Mono** (also not loaded → `Consolas`) for checksum, version chip, subscriber count, slide counter, error metadata.
- Icons: Font Awesome 7 Free solid (`fas`) + brands, rendered as inline SVG by the JS i2svg engine (class `fa fa-check`, `fa-solid fa-bars`, etc.).
- `body { font-size: 15px; line-height: 1.6; text-rendering: optimizeLegibility; -webkit-font-smoothing: antialiased; }`

### Scroll reveal (two mechanisms)
- **`useRevealOnScroll`** (composable, used by Services / Utilities / Partners / Contact / Checkout): on mount queries all `.animate` elements, creates one `IntersectionObserver` (`threshold: 0.01`, `rootMargin: 0px`), marks `isVisible[i] = true` the first time an element intersects and unobserves it. Templates bind `:class="{ 'slide-up': isVisible[i] }"`. CSS: `.animate { opacity:0; transform: translateY(30px); transition: opacity .6s ease-out, transform .6s ease-out }` → `.slide-up { opacity:1; transform:none }`. Index 0 is always the banner. `.animate.section` gets `scroll-margin-top: var(--nav-height)`.
- **Home sections** (`Section`, `Section2`, `HowItWorks`, `Brands`): each creates its own `IntersectionObserver` with `threshold: 0.2`, toggles a `visible` ref and disconnects. CSS `opacity:0; translateY(40px)` (brands 30px) → `.visible`, `0.8s ease`. Inside How-it-works the `.step-card`s additionally run `fadeInUp` keyframes with `--delay` 0/.15/.3s (0 on ≤900). Team cards on About use the same pattern with `--delay` = index×0.1s.
- Videos: a second observer (`threshold 0.1`) calls `video.play()` when in view and `pause()` when out; skipped entirely under `prefers-reduced-motion`. Videos are `<video loop playsinline preload="metadata" disablepictureinpicture disableremoteplayback aria-hidden>` with HEVC (`hvc1`) mp4 first and webm fallback, no controls, muted by attribute-less autoplay via JS.
- Reduced motion: `@media (prefers-reduced-motion: reduce)` zeroes all animation/transition durations and forces `.animate` visible; JS helper returns `"auto"` instead of `"smooth"` for programmatic scrolls.
